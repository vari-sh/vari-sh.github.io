I

Concept

Blood, bone, stone

{{ partial "cremisi/ornament.html" }}

Cremisi is a cabinet of materials: every hue comes from a real substance, desaturated, earthy, mineral.

The backbone never changes. Blood is the protagonist, bone is the text, stone is the ground. Everything else revolves around these three.

Its colours are wax, resin and oxidised copper, with two cold notes: lapis, ground for illuminated missals, and verdigris, the patina on bronze doors.

VII

Rite of entry

Install Cremisi

{{ partial "cremisi/ornament.html" }}

Sublime Text and VS Code are below. Further ports are available in the repository: vari-sh/Cremisi-Theme.

S

Sublime Text

  1. Download both variants below.
  2. Copy them into your Packages/User folder (Preferences → Browse Packages…).
  3. Open the command palette and run UI: Select Color Scheme.
Obsidian Ivory
V

VS Code

  1. Download the extension below.
  2. Open the command palette and run Extensions: Install from VSIX….
  3. Run Preferences: Color Theme and pick Cremisi Obsidian or Cremisi Ivory. To follow the system appearance:
