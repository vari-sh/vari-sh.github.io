I

Concept

Blood, bone, stone

{{ partial "cremisi/ornament.html" }}

CCremisi is a cabinet of materials: every hue comes from a real substance, desaturated, earthy, mineral.

The backbone never changes. Blood is the protagonist, bone is the text, stone is the ground. Everything else revolves around these three.

Its colours are wax, resin and oxidised copper, with two cold notes: lapis, ground for illuminated missals, and verdigris, the patina on bronze doors.

VII

Rite of entry

Install Cremisi

{{ partial "cremisi/ornament.html" }}

Sublime Text and VS Code are below. Further ports are available in the repository: vari-sh/Cremisi-Theme.

S

Sublime Text

  1. Install Cremisi Color Scheme from Package Control: open the command palette, run Package Control: Install Package and pick it. Delete any older copies of the schemes in Packages/User: they would override the package.
  2. Without Package Control or offline, download the package below and drop it into the Installed Packages folder, next to the one Preferences → Browse Packages… opens.
  3. Run UI: Select Color Scheme and pick Cremisi Obsidian or Cremisi Ivory. To follow the system appearance:
{{ transform.Highlight "{\n \"color_scheme\": \"auto\",\n \"dark_color_scheme\": \"Cremisi Obsidian.sublime-color-scheme\",\n \"light_color_scheme\": \"Cremisi Ivory.sublime-color-scheme\"\n}" "json" }}
Package Control .sublime-package
V

VS Code

  1. Install Cremisi from the Visual Studio Marketplace: search for it in the Extensions view, or press Ctrl+P and run ext install vari-sh.cremisi-theme.
  2. For VSCodium or an offline machine, download the extension below and run Extensions: Install from VSIX….
  3. Run Preferences: Color Theme and pick Cremisi Obsidian or Cremisi Ivory. To follow the system appearance:
{{ transform.Highlight "{\n \"window.autoDetectColorScheme\": true,\n \"workbench.preferredDarkColorTheme\": \"Cremisi Obsidian\",\n \"workbench.preferredLightColorTheme\": \"Cremisi Ivory\"\n}" "json" }}
Marketplace cremisi-theme-0.2.1.vsix
